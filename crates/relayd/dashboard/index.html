WHAT RELAY DOES

How RELAY helps

RELAY starts a local engine on this computer. It reads a folder you choose, remembers what changed, and gives you short results. Your project files stay in their folder.

Choose a folderAdd a local project below.
Scan its filesRELAY builds a file list without moving anything.
Run a checkUse Assets or File checks to inspect what you need.
Read the resultSee a short answer here, in the CLI, or through supported AI tools.
See how scanning, AI connections, and health work

RELAY leaves project files where they are. After a local scan, it can focus later checks on changed files instead of repeating every step.

Use these buttons yourself, or let a local AI tool use the RELAY CLI. It asks the same engine to do the work and returns short results first, with more detail available when needed. The optional MCP gateway exposes a limited read-only set of commands. This may save context and paid model calls; actual savings depend on the task and client.

Select a project, scan its files, then use Assets or File checks. Health shows whether RELAY's basic parts can respond; it does not prove a creator app or live game session works.

      Show or hide connection choices

      CLI: commands in a terminal

      The RELAY CLI is part of this installation. It talks to the same local engine as this screen. A Codex task or script can call it and receive a compact result, so it need not paste a whole project or long logs into chat.

      Open the terminal, then try relay doctor to check RELAY or relay commands to see what it can do.

      Checking whether a RELAY terminal can be opened here.

      MCP: a tool connection

      The optional local MCP gateway exposes a limited read-only set of RELAY commands. An MCP-capable client must be set up to connect to it. RELAY does not set up that client for you.

      See connection diagnostics

      ChatGPT desktop: regular Chat

      Install the optional DSI RELAY plugin from your local plugin list, then start a new Chat and ask: “Use RELAY to show what you can read.” Keep RELAY open while you chat. This connection can read short capability and saved-result summaries; it cannot change your projects.

      The plugin works in ChatGPT desktop after you enable it. ChatGPT web and mobile cannot run this local connection. Local Codex or another CLI-capable assistant can use RELAY through its CLI instructions. Actual token or credit savings have not yet been measured.
