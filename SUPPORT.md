# Preview support

For installation or benchmark problems, open a [GitHub issue](https://github.com/raiinman/DSI-RELAY/issues). Include the preview version, archive SHA-256, Windows version, report schema version, the fixed failure code, and the step that failed. Check the report before attaching it; remove any information you do not want public. Do not post credentials or private project content.

Use the [private security reporting channel](SECURITY.md) for suspected vulnerabilities. The preview has no production support or response-time commitment.
