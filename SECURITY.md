# Security reporting

The current development branch and local measurement preview are experimental. No RELAY version is declared production supported yet.

Report a suspected vulnerability privately through [GitHub's repository security advisories](https://github.com/raiinman/DSI-RELAY/security/advisories). Private vulnerability reporting is enabled for this repository. Include the affected revision or preview archive hash, Windows version, reproduction steps, and impact. Do not include credentials, private project content, or an exploit in a public issue.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/raiinman/DSI-RELAY/issues). The maintainer will triage reports; no response-time guarantee is offered during the preview.
